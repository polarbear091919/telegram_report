# Research Desk — 2026-09-15

## 화면 구성

기본 디자인은 밝은 배경과 대비가 높은 글자색을 사용하는 리서치 워크스페이스다.
승인된 가독성 프로토타입을 정식 스타일로 통합했으며, 공통 색상은
`frontend/src/theme.css`, 화면별 스타일은 `styles.css`와 `migration.css`에서 관리한다.
본문은 `--text-body`, 보조 정보는 `--text-secondary`, 상태 표시는 의미별 색상 변수를
사용한다. 리포트 제목 14px, 요약 13px, 날짜·발행처 12px을 기본으로 한다.
프로토타입 전용 파일이나 별도 적용 스위치는 사용하지 않는다.
정식 통합 전후 리포트·비교·커버리지·검토 및 모바일 비교·검토의 6개 화면에서
글자색, 배경색, 글꼴, 크기, 굵기, 줄 간격, 테두리색, 여백, 간격, 너비를
비교하여 차이 없음과 가로 넘침 없음을 확인했다. Vite production build도 통과했다.

- 기업 검색 및 기존 관심 기업 → 기업 리포트 라이브러리.
- 발행일, 발행처, 제목·한 줄 요약, 목표주가, 분석 상태를 한 행에 표시.
- 보고서 제목을 선택하면 옆에서 상세 내용을 읽고 원문 근거를 확인.
- 체크박스로 두 보고서를 담아 비교. 목록으로 돌아가거나 비교 화면의
  드롭다운으로 문서를 바꿀 수 있음.
- 두 보고서의 목표주가·EPS·ROE 차이를 먼저 확인하고, 실적 추정 표,
  투자 논리, 밸류에이션, PDF 나란히 보기로 이동.
- 원문에 근거한 항목과 모델이 도출한 논리 재검토 조건을 구분.

## 구현 범위

React + Vite (`frontend/`)와 FastAPI (`langgraph_tagger/workspace/`).
수집·태깅·DB 스키마는 그대로 사용한다. API가 기존 AnalyticsDB,
summary_store, compare_financials, extract_one, ground_metrics를 재사용한다.
기존 Streamlit의 기업 분석, 매크로/커버리지, 수동 검토 기능을 이 UI로 통합했다.

읽기는 분석을 실행하지 않는다. 사용자가 선택한 보고서의 분석 버튼을
눌렀을 때만 금융 정보를 추출·저장한다. 기존 상세 분석은 재사용한다.
여러 리포트의 체크박스를 선택하고 **선택한 N건 분석**을 누르면 선택한 ID만
순차 처리한다. 현재 실행 중인 요청이 끝난 뒤 남은 분석을 중지할 수 있고,
실패한 선택 리포트만 재시도할 수 있다. 동시 중복 요청은 거절한다.
금융 분석과 비교 대상은 단일종목 보고서이며, 산업 등 다른 유형도 목록에서
검색·열람할 수 있다. 선택만 하거나 화면을 열어서는 LLM을 호출하지 않는다.

비교는 선택한 두 문서를 발행일순으로 정렬한다. 다른 기업 또는 같은
문서의 비교는 거절한다. 동일 발행처와 발행처 간 차이를 구분하며,
기간·단위·회계 기준·시나리오가 맞는 추정치만 수치로 비교한다.
예전 비교 서술은 `prev_report_id`가 선택한 앞선 문서와 일치할 때만 표시한다.
선택한 두 보고서에 대한 비교 해석은 별도 버튼으로 명시적으로 생성한다.

## Streamlit 기능 이관

| 기존 기능 | 새 화면 |
|---|---|
| 산업(대/중)·제품별 커버리지와 상위 기업 | 리서치 커버리지 → 산업·제품 |
| 유형별 발행량, 분석 대상 외 자료 포함 | 리서치 커버리지 → 리포트 유형별 발행량 |
| 기간·일/주/월 집계, 표·CSV | 커버리지 및 기업 발행 추이 |
| 기업별 발행 추이·발행처 비중 | 기업 리포트 → 발행 추이 |
| 기업 검색·관심 기업·리포트 조회 | 기업 리포트 |
| 요약·변화 비교·금융 구조 | 개별 리포트 및 두 보고서 비교 |
| 검토 대기열·첫 3페이지·분류 결과 | 리포트 검토 |
| 승인·대상 제외·재태깅·건너뛰기·되돌리기 | 리포트 검토 우측 작업 영역 |

검토 변경은 기존 승인/제외/재태깅 규칙을 재사용한다. 되돌리기는 서버에 저장한
직전 상태만 복원하며, 이후 워커가 처리한 보고서는 덮어쓰지 않는다.
서버를 재시작하면 되돌리기 기록은 만료된다. 건너뛰기는 현재 브라우저 세션에만
적용된다. 재태깅 버튼은 대기열로 보내며 즉시 LLM을 호출하지 않는다.

목표주가 변화는 선택한 두 문서의 `target_price_new`로 계산한다.
각 문서에 적힌 `target_price_old`를 두 문서 간 비교에 섞지 않는다.

## 실행 및 운영

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-workspace.txt
pwsh -File scripts/start-workspace.ps1
```

주소: http://127.0.0.1:8520/

로컬 단일 사용자용이다. 인증 없는 이 서버를 외부 주소에 공개하지 않는다.
브라우저에 서비스 키나 로컬 파일 경로를 전달하지 않고, PDF는 보고서 ID로
조회하여 저장 디렉터리 내부의 PDF 파일만 제공한다.
